# Contributing

Use issues for non-sensitive bugs and proposals; send security reports to support@heisto.xyz. Work on a branch, explain the change and test it. Never include private keys, provider tokens, database exports, user prompts or environment files. Tests must use generated, test-only identities and never paid Mainnet transactions. Document compatibility, trust and dependency changes. Contributions are made under this repository's MIT license; third-party rights and trademarks remain with their owners.
